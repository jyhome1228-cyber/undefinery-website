02 — HOW WE WORK

FROM UNDEFINED PROBLEM TO WORKING SYSTEM

UNDERSTAND → DEFINE → DESIGN → BUILD → OPERATE

프로젝트를 단순 제작 순서가 아니라 사업을 이해하고 기준을 세운 뒤, 실제 운영까지 이어지는 하나의 흐름으로 관리합니다.

01

Understand

사업과 현재 상황 이해

자료, 시장, 고객과 조직의 현실을 살펴 프로젝트의 출발점을 정리합니다.

02

Define

문제와 방향 정의

무엇을 해결하고 어떤 기준을 만들어야 하는지 우선순위를 정합니다.

03

Design

전략과 경험 설계

브랜드 언어, 시각 체계와 고객이 경험하는 모든 접점을 설계합니다.

04

Build

결과물과 시스템 구축

웹, 콘텐츠, 문서, 기능과 업무 체계를 실제 사용 가능한 형태로 만듭니다.

05

Operate

운영과 지속 개선

브랜드 자산과 시스템을 관리하고 변화에 맞춰 계속 확장합니다.
